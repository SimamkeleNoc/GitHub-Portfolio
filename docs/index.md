# PRP370S Work-Integrated Learning Portfolio

## GuardPulse — E-commerce Development Project

Welcome to my PRP370S portfolio. This portfolio presents evidence of my individual development work on GuardPulse, a South African online store for security cameras and related home-security products.

I worked independently on the project, developing features in stages and fixing issues as they arose. Git and GitHub commits were used to track code changes. The portfolio documents the project, supporting evidence, and my reflection on the development process.

## Project Evidence

The [GuardPulse evidence folder](evidence/README.md) contains screenshots of the live store, product catalogue, shopping cart and checkout page.

These screenshots demonstrate visible functionality. They should be considered alongside the written explanations and reflections in the portfolio sections.

## Project Technology

- **Frontend:** React, TypeScript and Vite
- **Backend:** TypeScript and Hono
- **Database:** PostgreSQL on Neon
- **Hosting:** Netlify for the frontend and Vercel for the backend
- **Integrations:** PayFast, The Courier Guy, Cloudflare and Resend

The store is live at [guardpulse.co.za](https://guardpulse.co.za/). PayFast remains in sandbox mode while account verification is pending, so real payments are not yet enabled.
